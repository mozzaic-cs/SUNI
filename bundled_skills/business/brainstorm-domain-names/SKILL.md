# Brainstorm and check domain names

Use for naming a project or finding a domain.

## Steps
1. Clarify the project, vibe, and any keywords to include/avoid.
2. Brainstorm 15-25 candidates across styles (literal, invented, compound, playful).
3. For the top picks, `web_search` / `web_fetch` a registrar or WHOIS to gauge
   availability (note this is a hint, not a guarantee).
4. Present a shortlist with rationale and availability notes.
