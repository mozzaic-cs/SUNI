# Tailor a resume to a job description

Use for tailoring a CV or resume to a specific job.

## Steps
1. Read the job description; extract required skills, keywords, and priorities.
2. Read the base resume (`read_file` or pasted text).
3. Rewrite the summary + bullet points to foreground matching experience and mirror the
   job language. Never invent experience the user does not have.
4. Produce the result and offer `create_pdf` for a clean, ATS-friendly PDF.
