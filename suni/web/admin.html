Channels — Discord

Paste both tokens, add a channel id to the allow-list, then Save — it starts immediately (no restart).

Embeddings (memory)

        

          
          
          
Episodic-memory embeddings run independently of the chat backend. Host-swap is safe; changing the model is not — a different embedding model requires re-embedding existing memory (reembed_memory.py), or memory writes are refused on a dimension mismatch.

Audit retention

        

          
          
          
Below 180 days. If this deployment is a high-risk AI system, the EU AI Act (Art. 26(6)) requires its automatically generated logs to be kept for at least six months. GDPR Art. 5(1)(e) pushes the other way — this table holds usernames, IP addresses and query previews — so the balance is yours to strike, not SUNI's.

          
          
Audit rows older than this are deleted once a day. 0 = keep everything (the default). The trail records what SUNI did and on whose behalf; it cannot be reconstructed after a purge.

        third party. Local logging always continues — shipping is additional, never a
        replacement.
