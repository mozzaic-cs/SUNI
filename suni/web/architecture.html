20–40%
Stage 0 of compressor — runs before any LLM call.
Word-bigram Jaccard ≥ 0.82 → shorter duplicate dropped.

A4 · FAISS IVF-PQ
32×
Migrate FlatIP → IndexIVFPQ (nlist=256, M=48, nbits=8).
Vector: 384 × 4B = 1 536B → 48B per chunk.
Recall@10 ~97% · nprobe=32 · search ~2ms vs 0.5ms.
Admin: POST /api/knowledge/compress · one-time, ~60s.
Requires ≥10 240 vectors to train codebook
A5 · Smart Excerpts
cleaner
_smart_excerpt() in document_chunker.py.
Trims to last .!?\\n within 500 chars → clean sentence end.
Falls back to word boundary, then hard cut (never mid-word).
Fixes KB search result fragments and injected [DOC] entries.
No size change · improves retrieval quality

agents.py · memory/agents/{slug}/AGENT.md
Agent Profiles
A prompt, an optional model, an optional narrowing of tools Stored as Markdown + YAML frontmatter beside a SQLite index, so a definition stays readable and editable outside the app
Sharing mirrors project_members: owner / editor / viewer
Model pinned by a profile suppresses tier escalation — otherwise the choice would be swapped out mid-run
A profile naming an UNREGISTERED tool is warned about: the intersection keeps the name, the registry returns nothing, and the model narrates instead of calling — which reads as a weak model and is not
effective_grants() · resolved per invocation
Narrowing, never widening
Tools & MCP INTERSECT with the caller's role; blocks UNION Re-derived every run, never stored — AGENT.md is a file a user can edit
A profile cannot grant a conversation mode the role lacks
Without this an admin-authored agent in a dropdown would be privilege escalation for whoever picked it
schedule_intent.py · _handle_schedule_direct
Deterministic intent
Cadence, delivery and agent parsed by regex, not chosen by the model Measured: at the core tier the same prompt picked four different wrong tools across four runs, with the right one registered and hinted
Missing detail is ASKED for, never invented
No capable local tier → automatic escalation to T5
schedules.py · _schedule_runner
Scheduled Invocations
Replays a PROMPT through the orchestrator, not an OS command Runs as the owner, role read AT FIRE TIME — not a snapshot, which would preserve permissions the owner has since lost
Delivery performed by the runner: unattended runs have no approver, so the model never chooses a recipient
Unknown cadence refused, never rounded · missed slots do not stack
invoke_agent · list_agents · _handle_agent_direct
Delegation
"Ask the X agent to…" hands the task to that agent The NAME is extracted by regex, not chosen by the model — measured, the core tier picked four different wrong tools across four runs
Sub-turn grants intersect the CALLING turn's, not the raw role, or a narrow agent delegates its way back to full reach
An agent that DECLARES tools is floored at a tier that can emit well-formed calls, and escalates to T5 when no local tier qualifies — a pinned model is never overridden
Depth cap 1: agents may be invoked, may not invoke · unknown name refused, never self-handled
mode=collaborate → orchestrate.py
Panel Agents
An agent whose model is a PANEL, not a model Draft → cross-critique → synthesise across the pool, answered in that agent's voice. Per-agent pool override
Persona shapes only the SYNTHESIS — applying it to every seat would correlate the models, which is the whole point of a panel
Cloud models: this leaves the machine, unlike the single-model path
max_steps · max_runs_day
Ceilings
The instance cap bounds one turn; these bound a day of them A schedule firing every 15 minutes has no natural stopping point
max_steps applies as a MINIMUM against the instance cap — a profile can tighten it, never raise it, the same rule as its tool grants
Runs counted from the audit trail, not a profile counter that would drift on a failed run
POST /api/agents/{slug}/dry-run
Preview before trust
What it WOULD call, and what it may reach — executing nothing Reports the resolved grants too: what an agent could reach is the governance question, and another task might choose differently
Unlike task mode, the plan is NOT stashed — an executable plan left behind turns a preview into something one word could fire
audit_log.agent_slug · agent.invoked
Traceable by agent
Which agent answered, and what it was allowed to reach then Per-request row carries agent_slug; a governance event records the RESOLVED grants — model, mode, tool count, MCP prefixes
Grants are re-derived each run, so the profile as it stands later is not evidence of what applied

web.py · gen_cert.py
TLS on First Run
A self-signed certificate is generated before the first request Both quickstarts say to open https://localhost:8765 — nothing used to create a certificate, so that URL failed and users fell back to http, creating the admin password over cleartext
SANs are built from the host — hostname, FQDN and every non-loopback address — so SUNI is reachable by LAN IP. Hardcoding localhost/127.0.0.1 made every remote client a name mismatch, which browsers often will not let you past
SUNI_CERT_HOSTS adds a NAT/VPN address the host cannot see · SUNI_NO_TLS=1 opts out, for a proxy that terminates TLS itself
