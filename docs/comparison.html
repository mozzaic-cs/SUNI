The short version

Why these three. This table is a development artifact before it is a public one. OpenClaw, Hermes and Turnstone are the projects SUNI was built to reach feature parity with, and the comparison grew alongside the roadmap over the development cycle — an empty cell in SUNI's column was usually the argument for building the next thing. It is published as it was used, which is also why it is candid about where SUNI still trails.

All four are self-hostable and local-capable — they diverge on surface (how you talk to them) and scope (personal assistant vs. cluster orchestrator). In one line each:

  • SUNI — the most feature-complete for a single-node personal / small-business deployment, and the only one that is voice-first with a 3D persona (Orb / Chat / Face + webcam vision), backed by strong governance and built-in resiliency. Now reachable across Telegram / Discord / Slack / WhatsApp as well as its web UIs, and the only one that can have multiple frontier models collaborate on a single answer. Trade-off: private / bespoke and single-node.
  • Hermes — the most mature and widely adopted: a production-grade open agent (MIT) with 20+ messaging channels, six execution backends, and a formal self-improvement loop. The safest general-purpose choice.
  • OpenClaw — the accessible on-ramp: it lives inside your existing chat apps (WhatsApp / Discord / Telegram), speaks to any major LLM, and sandboxes tools well. The lineage both SUNI and Hermes grew from.
  • Turnstone — the headless tool-agent orchestrator for hardware you control: provider-agnostic, MCP, cluster-scalable. No voice or persona — built for engineering / DevOps agent workloads.

Overall: for a general, ready-to-adopt agent, Hermes leads on maturity and reach; SUNI is the richest and most differentiated for its intended purpose — a private, voice-forward personal / small-business assistant; OpenClaw is the simplest entry point; and Turnstone wins where you need cluster-scale tool orchestration. There is no single winner — the right pick follows the use case.
